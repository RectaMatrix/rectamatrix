# Security policy

## Supported versions

Only the latest preview release and the current `main` branch receive security
fixes. RectaMatrix is experimental and must not be treated as a security or
authentication boundary.

## Report a vulnerability

Please use the repository's private
[GitHub Security Advisory form](https://github.com/RectaMatrix/rectamatrix/security/advisories/new).
Include the affected version, reproduction input, expected impact, and any
suggested mitigation. Please do not publish malicious samples or an unfixed
vulnerability in a public issue.

Reports are acknowledged and handled on a best-effort basis while the project
is in preview. A coordinated disclosure date will be agreed when a fix is
required.
